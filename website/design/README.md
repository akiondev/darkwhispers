# DarkWhispers identity

`hooded-vampire.png` is the approved original generated brand artwork: a dark
hood and red eyes, without a visible face or fangs. The website, favicon,
launcher interface and native app icons use resized exports of this same image.
The previous crescent/star and crystal marks are retired.

The wordmark uses the Black weight of Grenze Gotisch, licensed under the SIL
Open Font License 1.1. Its self-hosted Latin WOFF2, license and source metadata
are in `../public/assets/fonts/`. No Google Fonts request runs in the product.

`launcher/build-tools/prepare.py` regenerates the app icons and copies the shared
logo/font assets into the launcher. Keep this master and all runtime exports in
the public repository so visual changes can be reviewed.
