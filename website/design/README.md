# DarkWhispers identity

hooded-vampire.png is the approved original brand artwork: a dark hood and red
eyes, without face or fangs. It identifies only the website and launcher.

The wordmark uses the exact Cinzel Bold (700) outlines from the requested DaFont
package. The self-hosted Latin WOFF2 subset is renamed DarkWhispers Wordmark as
required by the original reserved font name terms. SOURCE.txt and OFL.txt beside
the font record its attribution, source hash and complete embedded license.

The raid addon has its own original gothic shield and crossed tools mark,
rendered as SVG for web/launcher and RGBA TGA for WoW. No vampire is used for the
addon. The previous crescent/star and crystal brand marks remain retired.
