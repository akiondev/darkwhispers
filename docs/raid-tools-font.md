# Raid Tool font

Carlito Regular is included unmodified from the Google Fonts source:
https://github.com/google/fonts/tree/main/ofl/carlito

SHA-256: f6418f708baede9789daef5d458c0f53d2a888af9820e8062934e504fedc6595

The full SIL Open Font License and copyright notice travel with every addon
installation in Core.lua. This keeps compatibility with existing signed
installers, which already allow TTF fonts. No system font dependency or network
font loading is introduced.
